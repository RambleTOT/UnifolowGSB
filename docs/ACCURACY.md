# Проверка точности подсчёта

По решению пользователя сверка с ручным подсчётом не проводится
(см. `DEVIATIONS.md`). Здесь фиксируются прогоны системы: видео, разметка,
параметры и то, что насчитала система. Как только появится видео объекта и
эталонные числа, таблица дополняется столбцами «вручную» и «расхождение».

Прогон выполняется одной командой:

```bash
python scripts/evaluate.py --video data/videos/<файл>.mp4 --markup <разметка>.json --output <ролик>.mp4
```
